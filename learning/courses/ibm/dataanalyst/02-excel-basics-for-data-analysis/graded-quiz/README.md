# Graded Quiz - Questions and Answers

## Module 1 - Introduction to Data Analysis Using Spreadsheets

1. **You need to analyze a sales dataset of about 15,000 rows on your laptop. You want to sort, filter, and visualize the data without installing specialized analytics software. Which tool is the best starting point?**
   - [x] A spreadsheet application such as Microsoft Excel or Google Sheets
   - [ ] A presentation tool such as PowerPoint or Google Slides
   - [ ] A plain text editor such as Notepad
   - [ ] A calculator and handwritten notes

   Answer: Correct! A spreadsheet is well suited to organizing, filtering, and visualizing a moderately sized dataset on a typical computer.

2. **A non-profit needs a low-cost way to track donor information and quarterly donations. Staff work from different locations and may connect the spreadsheet to online forms. Which option best fits these needs?**
   - [ ] A local open-source spreadsheet with no cloud access
   - [x] A web-based spreadsheet such as Google Sheets in a shared Google account
   - [ ] A paper ledger maintained by one staff member
   - [ ] A paid desktop spreadsheet installed on one office computer

   Answer: Correct! A web-based spreadsheet supports shared access across locations and works well with online tools.

3. **A small business owner wants a spreadsheet tool with useful analysis features but has a very limited budget. Which recommendations are appropriate? Select all that apply.**
   - [x] Suggest Google Sheets because it is free with a Google account and supports many common analysis tasks
   - [ ] Recommend notebooks and calculators to avoid software costs
   - [x] Suggest LibreOffice Calc because it is free, open source, and includes features such as charts and pivot tables
   - [ ] Recommend the paid desktop version of Microsoft Excel as the only option
   - [ ] Recommend Smartsheet because it is mainly positioned as a project management tool
   - [ ] Recommend Apple Numbers when the business uses only Windows PCs

   Answer: Correct! Google Sheets offers a strong balance of cost and capability for many everyday analysis needs. LibreOffice Calc provides useful analysis tools without a licensing cost.

4. **You are using a free browser-based spreadsheet and notice that some advanced analysis features are unavailable. Which situation best explains this?**
   - [ ] You are using a custom spreadsheet built only for advanced analysis
   - [ ] You are using LibreOffice Calc on your computer
   - [x] You are using Excel for the web, which has fewer advanced features than the desktop version
   - [ ] You are using the full desktop version of Microsoft Excel

   Answer: Correct! Excel for the web is the browser-based version and does not include all advanced desktop features.

5. **You need to analyze a dataset with several hundred thousand rows and share the work with multiple analysts. You are considering a spreadsheet as the main tool. Which considerations are appropriate? Select all that apply.**
   - [x] Consider whether a database or other specialized tool may be more suitable
   - [ ] Assume any spreadsheet will handle any size of dataset equally well
   - [ ] Assume the spreadsheet will automatically preserve a complete step-by-step record of every change
   - [x] Consider whether the data size could create performance or stability problems
   - [ ] Avoid charts and pivot tables in every large spreadsheet
   - [ ] Avoid spreadsheets for all analysis tasks, regardless of data size

   Answer: Correct! For very large or complex data work, another tool may be a better fit. Very large datasets can make spreadsheets slow or unstable.

6. **A team must understand exactly how a dataset was cleaned and transformed over time. What is a key limitation of relying on a spreadsheet alone for that need?**
   - [ ] A spreadsheet cannot contain more than one worksheet
   - [x] A spreadsheet does not clearly preserve the exact sequence of steps used to transform the data
   - [ ] A spreadsheet cannot sort or filter data
   - [ ] A spreadsheet cannot store numeric values

   Answer: Correct! A spreadsheet often shows the final state well, but not the full process used to reach it.

7. **You are analyzing a mid-sized dataset of customer transactions in a spreadsheet. Which approaches are appropriate? Select all that apply.**
   - [x] Use filtering and sorting to explore patterns in the data
   - [ ] Keep the data unstructured rather than in rows and columns
   - [ ] Avoid formulas because formulas reduce accuracy
   - [ ] Use a handheld calculator for each calculation and type the results into the spreadsheet
   - [x] Use formulas to calculate results automatically across many rows
   - [x] Use pivot tables and charts to summarize and visualize transaction trends

   Answer: Correct! Filtering and sorting help you inspect records and identify useful patterns efficiently. Formulas help perform repeated calculations accurately and efficiently. Pivot tables and charts are useful for condensing and presenting patterns in transaction data.

8. **You have worksheets named “January Sales,” “February Sales,” and “March Sales.” You now want a worksheet that summarizes first-quarter results. What is the most appropriate first step?**
   - [ ] Use the “March Sales” worksheet for the summary without renaming it
   - [x] Insert a new worksheet, name it “Q1 Summary,” and keep the monthly worksheets
   - [ ] Delete the monthly worksheets and create one blank worksheet
   - [ ] Rename “January Sales” as “Q1 Summary” and replace the January data

   Answer: Correct! A separate summary sheet preserves the source detail while creating a clear place for quarterly totals.

9. **You are working in a large worksheet and want to find the last row in a contiguous column of data, starting from the first data cell in that column. Which action is most efficient?**
   - [ ] Press Ctrl+End and use that location as the end of the same column
   - [x] Select the first data cell and press Ctrl+Down arrow
   - [ ] Press Ctrl+Home and then use Page Down repeatedly
   - [ ] Scroll down manually until the data appears to end

   Answer: Correct! This shortcut moves to the edge of the current data region in that column.

10. **You want to work more efficiently in Excel by using keyboard shortcuts. Which shortcuts are correctly matched to their tasks? Select all that apply.**
    - [ ] Ctrl+Z makes selected text bold
    - [x] Ctrl+O opens a workbook
    - [x] Ctrl+S saves the current workbook
    - [x] Ctrl+F1 expands or collapses the ribbon
    - [x] Ctrl+C copies selected cells and Ctrl+V pastes them
    - [ ] Ctrl+W pastes clipboard contents

    Answer: Correct! Ctrl+O opens the command for selecting and opening a file. Ctrl+S saves the current file. Correct! These shortcuts are the standard copy and paste commands. Ctrl+F1 toggles the ribbon display.

## Module 2 - Getting Started with Using Excel Spreadsheets

1. **How can you zoom to a specific area of data in an Excel spreadsheet?**
   - [ ] Use the 100% button
   - [ ] Use the Zoom button
   - [ ] Use the Freeze Frames option
   - [x] Use the Zoom to Selection button

   Answer: The Zoom to Selection button allows you to automatically adjust the zoom level to fit the selected range of cells, making it easier to view specific data.

2. **What do you use the AutoFill feature for?**
   - [ ] Drag selected data to another place
   - [ ] Paste data in a cell with the same column width settings
   - [ ] Move or copy data between spreadsheets
   - [x] Automatically fill cells with data in a sequential series or pattern

   Answer: AutoFill is used to fill cells automatically for you when the data is identified to be in a sequential series or pattern.

3. **What character do you type first when you want to start writing a formula?**
   - [ ] Plus sign '+'
   - [x] Equal sign '='
   - [ ] Percentage sign '%'
   - [ ] Division sign '/'

   Ansawer: You type the '=' character first when you want to start writing a formula.

4. **What is one of the functions found in the AutoSum drop-down list?**
   - [x] Count Numbers
   - [ ] General
   - [ ] Accounting
   - [ ] Number

   Answer: Count Numbers is one of the functions found in the AutoSum drop-down list, The other options are Sum, Average, Max, and Min.

5. **In Excel Desktop, what is one of the function categories on the Formulas tab in the Function Library group?**
   - [ ] Medical
   - [ ] Analytical
   - [x] Lookup & Reference
   - [ ] Functional

   Answer: Lookup & Reference is one of the function categories on the Formulas tab in the Function Library group.

6. **How do you make a cell reference absolute in a formula?**
   - [ ] Put a percentage sign (%) behind the column or row identifiers in the formula
   - [ ] Put a plus sign (+) between the column and row identifiers in the formula
   - [x] Put a dollar sign ($) in front of the column and/or row identifiers in the formula
   - [ ] Put an asterisk (\*) in front of the column or behind the row identifiers in the formula

   Answer: Putting a dollar sign ($) in front of the column and/or row identifiers is how you make a cell reference absolute in a formula.

7. **Formula errors in Excel are preceded by a hash symbol (#). What does it mean when multiple hash symbols exist in a cell?**
   - [x] Column isn't wide enough or it contains negative date or time values
   - [ ] Formula contains unrecognized text
   - [ ] Formula is missing a cell reference
   - [ ] Formula contains multiple errors

   Answer: When you see multiple hash symbols in a cell, it means that either the column isn't wide enough to display the full data or it contains negative date or time values.

## Module 3 - Cleaning Data

1. **What is one of the issues that empty rows cause in your spreadsheet?**
   - [ ] Indexing function error
   - [x] Formula errors
   - [ ] Data will be hidden
   - [ ] Spell-check will fail

   Answer: Having empty rows in your spreadsheet can cause errors in your formulas.

2. **How to remove all empty rows at the same time in an imported spreadsheet?**
   - [ ] You must delete the empty rows one at a time
   - [ ] Use Search & Replace to look for empty rows and delete
   - [ ] Use Remove Duplicates to remove empty rows
   - [x] Select all rows and then filter for Blanks, select these and then delete

   Answer: To remove all empty rows at the same time in your imported spreadsheet, select all rows, filter for Blanks, then select these and delete

3. **There are two methods to locate and remove duplicated rows in Excel, what is the easiest way?**
