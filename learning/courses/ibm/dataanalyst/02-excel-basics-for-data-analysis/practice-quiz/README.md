# Practice Quiz - Questions and Answers

## Module 1 - Introduction to Data Analysis Using Spreadsheets

1. **Which spreadsheet application is described as the most commonly used and the most fully featured?**
   - [ ] Zoho Sheet
   - [ ] Google Sheets
   - [ ] LibreOffice Calc
   - [x] Microsoft Excel

   Answer: Correct! This matches the application identified as the leading spreadsheet tool in both adoption and feature set.

2. **What is a key difference between the desktop version of Microsoft Excel and Excel for the web?**
   - [ ] The desktop version is mainly used for viewing files online
   - [x] Excel for the web includes fewer advanced features
   - [ ] The desktop version includes more advanced features
   - [ ] Excel for the web is only available through a paid subscription

   Answer: Correct! This captures the main limitation of the web version compared with the desktop application.

3. **Which task is identified as a use of spreadsheets for a Data Analyst?**
   - [x] Cleaning data to remove duplicates and errors
   - [ ] Editing video for a presentation
   - [ ] Building a website for customers
   - [ ] Writing software to compile an application

   Answer: Correct! This is one of the data analysis tasks specifically associated with spreadsheet use.

4. **Which option shows a correctly written cell reference in Excel?**
   - [x] M20
   - [ ] m-20
   - [ ] 20M
   - [ ] M:20

   Answer: Correct! This follows the standard Excel format for identifying one cell.

5. **What is a cell range most commonly used for in a spreadsheet?**
   - [ ] Renaming multiple worksheets at once
   - [ ] Moving all workbook data into one worksheet
   - [x] Referring to multiple cells in a calculation or formula
   - [ ] Protecting a group of cells from changes

   Answer: Correct! This matches the main use described for a selected range of cells.

## Module 2 - Getting Started with Using Excel Spreadsheets

1. **Which of the following is a valid way of editing existing data in a cell? Select all that apply.**
   - [x] Select the cell you want to edit and then click the formula bar
   - [ ] Press CTRL+N
   - [x] Press F2
   - [ ] Select the cell you want to edit and press Enter

   Answer: Press F2 or Select the cell you want to edit and then click the formula bar are valid ways of editing the existing data in a cell.

2. **In Excel for the web, how can you format data in cells to use a currency? Select all that apply.**
   - [x] Right-click on a cell and select Number Format
   - [ ] Select 'Currency' from the Alignment group on the ribbon.
   - [ ] Select the data and click the Decrease Decimal button
   - [x] Select "More Number Formats" from the Number Format drop-down list in the Number group

   Answer: Select "More Number Formats" or Right-click on a cell and select Number Format will enable you to format your data as currency.

3. **What is one of the key components of a typical formula?**
   - [ ] Calculation
   - [ ] Percentage
   - [x] Reference
   - [ ] Division

   Answer: A reference to cells, ranges, or named ranges is a key component of a formula in Excel. References indicate where the formula should retrieve data or perform calculations.

4. **What happens when you use the median calculation but select an even number of values in a range?**
   - [x] Returns the middle figure between the two middle values in the selected range
   - [ ] Returns both of the middle values of the selected range
   - [ ] Returns one of the middle values of the selected range
   - [ ] Divides the selected range in half

   Answer: The median is a midway point between a range of values, so if you select an odd number of values, it uses the middle value, but when you select an even number of values, the median is the midway point between the two middle values.

5. **What are Excel cell references by default?**
   - [x] Relative references
   - [ ] Absolute references
   - [ ] Cell references must be assigned
   - [ ] Mixed references

   Answer: Relative references are the default in Excel. When a formula containing relative references is copied to other cells, the references adjust based on the new location.

6. **When creating formulas, what is a mixed reference?**
   - [ ] Both cell references are manually assigned
   - [ ] One cell reference is absolute; the other must be manually assigned
   - [ ] Both cell references are either absolute or relative
   - [x] One cell reference is absolute, the other one is relative

   Answer: A mixed reference in Excel is where one part of the reference (either row or column) is fixed (absolute) while the other part can change as the formula is copied.
