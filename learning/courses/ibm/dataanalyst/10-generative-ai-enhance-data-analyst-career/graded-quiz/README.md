# Graded Quiz - Questions and Answers

## Module 1 - Data Analytics and Generative AI

1. **Which ability of Generative AI can data professionals leverage to overcome limited data availability?**
   - [x] It creates synthetic data sets and augments the existing ones.
   - [ ] It collects data from all available resources.
   - [ ] It focuses on optimizing algorithms for smaller data sets.
   - [ ] It reduces the complexity of models, making them less reliant on extensive training data.

   **Answer:** Generative AI can create synthetic data sets and augment the existing ones for robust analysis and model training.

2. **How does Generative AI help query databases?**
   - [ ] It focuses on optimizing algorithms for smaller data sets.
   - [x] It can formulate complex queries, optimize database interactions, and adapt to evolving data structures.
   - [ ] It is primarily focused on data analysis and pattern recognition.
   - [ ] It can generate visually appealing representations and narrative elements.

   **Answer:** Generative AI brings efficiency and innovation in querying databases.

3. **Which ability of Generative AI can data professionals leverage to create compelling narratives?**
   - [ ] The ability to focus on data analysis and pattern recognition
   - [ ] The ability to formulate complex queries
   - [ ] The ability to rely on static, pre-defined templates and graphics
   - [x] The ability to generate story elements, highlight key insights, and provide a cohesive structure

   **Answer:** Generative AI can generate story elements, highlight key insights, and provide a cohesive structure, transforming raw data into compelling narratives.

4. **Which of the following AI engines integrates the capabilities of Generative AI and machine learning with enterprise-grade features of the Alteryx Analytics Cloud Platform?**
   - [ ] Palantir AIP
   - [x] AiDIN
   - [ ] Haptik
   - [ ] DataRobot

5. **Which of the following is a comprehensive data science and machine learning platform incorporating Generative AI capabilities for predictive modeling and data augmentation?**
   - [ ] Tableau

7. **Which of the following SQL queries will generate if you type "What is the count of rows in the Boston_house_price data set" in the prompt box of a generative AI SQL query tool?**
   - [x] `SELECT COUNT * FROM Boston_house_price`
   - [ ] `SELECT COUNT FROM Boston_house_price`
   - [ ] `SELECT * FROM Boston_house_price`
   - [ ] `SELECT COUNT * Boston_house_price`

   **Answer:** To retrieve the count of rows in a database, you can use the following SQL statement: `SELECT COUNT * FROM <database name>`.

8. **Which of the following describes how Generative AI enhances the extraction of insights from data?**
   - [x] By identifying hidden patterns and correlations, generating hypotheses and explanations, and providing personalized insights
   - [ ] By imputing data, detecting anomalies, and normalizing data
   - [ ] By enabling natural language queries, generating SQL queries automatically, and providing real-time query responses
   - [ ] By providing a representative training data set, reducing the impact of data scarcity and bias, and providing valuable insights into potential outcomes and risks

   **Answer:** By identifying hidden patterns and correlations, generating hypotheses and explanations, and providing personalized insights, Generative AI can enhance the extraction of insights from data.

9. **Which of the following tasks does Generative AI automate to enhance data preparation?**
   - [ ] Identification of patterns and correlations
   - [x] Data anomaly detection
   - [ ] Generation of SQL queries
   - [ ] Generation of personalized insights

   **Answer:** By automating data anomaly detection, Generative AI identifies and corrects outliers or errors in data, thus improving data quality.

10. **Which of the following is the purpose of Q&A for data?**
    - [ ] Predicting future question trends and patterns in time-dependent data and preparing responses accordingly
    - [x] Utilizing machine learning and natural language processing algorithms to comprehend questions and provide relevant responses
    - [ ] Learning the latent code to encapsulate the core information of customer data
    - [ ] Analyzing customer behavior and purchase patterns to provide relevant responses to customer queries

    **Answer:** Q&A for data involves utilizing machine learning and natural language processing algorithms to interpret queries and provide accurate responses.
