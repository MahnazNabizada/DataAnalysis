# Practice Quiz - Questions and Answers

## Module 1 - Visualizing Data using Spreadsheets

1. **What distinguishes a bar chart from a column chart?**
   - [x] A bar chart displays categories on the vertical axis, while a column chart displays categories on the horizontal axis.
   - [ ] A bar chart is used only for percentages, while a column chart is used only for whole numbers.
   - [ ] A bar chart must display categories in descending order, while a column chart can display categories in any order.
   - [ ] A bar chart compares only one data series, while a column chart compares multiple data series.

   Answer: A bar chart displays categories on the vertical axis, while a column chart displays categories on the horizontal axis.

2. **Which chart type displays data as nested rectangles?**
   - [ ] Sparkline
   - [ ] catter chart
   - [x] Treemap
   - [ ] Bubble chart

   Answer: A treemap displays hierarchical or part-to-whole data using nested rectangles.

3. **Which chart type is most appropriate for showing how a value changes over a sequence such as months or quarters?**
   - [ ] Scatter chart
   - [ ] Pie chart
   - [ ] Treemap
   - [x] Line chart

   Answer: A line chart is commonly used to show trends and changes over time or another ordered sequence.

4. **When you filter a PivotChart that is linked to a PivotTable, what happens to the connected PivotTable?**
   - [ ] Only the chart changes; the PivotTable changes after the workbook is reopened.
   - [ ] You must refresh the PivotTable manually before the filter appears there.
   - [ ] You must apply the same filter separately in the PivotTable Fields pane.
   - [x] The connected PivotTable updates automatically to reflect the same filter.

   Answer: A PivotChart and its connected PivotTable are linked, so filtering one immediately updates the other.

## Module 2 - Creating Advanced Charts

1. **How does a treemap display the proportion of data represented?\***
   - [ ] As numerical values
   - [ ] As data points on a line
   - [x] As rectangular shapes
   - [ ] As columns

   Answer: A treemap represents data as a series of rectangular shapes.

2. **What are scatter charts commonly used for?**
   - [x] To compare statistical, scientific, and engineering data values
   - [ ] To compare sales, and inventory data values
   - [ ] To display distribution of data grouped into bins
   - [ ] To compare values across hierarchy levels

   Answer: Scatter charts are commonly used to compare statistical, scientific, and engineering data values.

   - [ ] Highlight the column, then right-click the intended cell location, and select Insert.
   - [ ] Right-click the intended cell location, and select Paste.

   Answer: On the worksheet select a cell and Excel will add the cell reference to the Location Range box for you and Enter the cell reference in the Location Range box are the two methods you can use to specify the location of a sparklines visualization.

4. **What's one data type intended for waterfall charts?**
   - [x] Financial data
   - [ ] Progressively decreasing proportions
   - [ ] Stock performance data
   - [ ] Non-comparable categories

   Answer: Waterfall charts are suitable for displaying data which represents inflows and outflows, such as financial data
