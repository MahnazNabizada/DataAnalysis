# Graded Quiz - Questions and Answers

## Module 1 - Visualizing Data using Spreadsheets

1. **What are line charts best suited to show?**
   - [ ] Hierarchical relationships using nested rectangles
   - [x] Trends or changes in related data over time
   - [ ] The frequency distribution of values across bins
   - [ ] The composition of a whole at a single point in time

   Answer: Line charts are best for showing how related values change across time or another ordered sequence.

2. **In a pie chart, what do all slices together represent?**
   - [ ] The largest category only
   - [x] 100% of the whole
   - [ ] The categories with the highest values only
   - [ ] The average value of all categories

   Answer: The slices in a pie chart add up to the entire whole, which is 100%.

3. **Which chart type is commonly used to compare values across categories?**
   - [ ] Scatter chart
   - [x] Bar chart
   - [ ] Funnel chart
   - [ ] Bubble chart

   Answer: A bar chart is one of the most common chart types for comparing values across categories.

4. **Which pair of software programs is commonly used to analyze data and present key findings in a data story?**
   - [ ] Google Docs and Word
   - [x] PowerPoint and Excel
   - [ ] Db2 and SQL
   - [ ] Google and Bing

   Answer: Excel is commonly used to analyze and visualize data, while PowerPoint is often used to present the key findings clearly.

5. **Which chart type is best for showing each car model's share of total unit sales?**
   - [ ] Bar chart
   - [x] Pie chart
   - [ ] Line chart
   - [ ] Funnel chart

   Answer: A pie chart is designed to show how each category contributes to the total.

6. **How does a PivotChart differ from a standard chart in Excel?**
   - [ ] A PivotChart requires the source data to stay in its original worksheet layout
   - [ ] A PivotChart cannot be formatted like other Excel charts
   - [ ] A PivotChart always displays percentages instead of actual values
   - [x] A PivotChart uses data summarized in a PivotTable

   Answer: A PivotChart is linked to a PivotTable and displays the summarized data from it.

7. **What is the main difference between an area chart and a column chart?**
   - [ ] An area chart is used only for percentages, while a column chart is used only for counts
   - [x] An area chart fills the space beneath a line to emphasize magnitude over time, while a column chart uses vertical bars to compare categories
   - [ ] An area chart has no axes, while a column chart has axes
   - [ ] An area chart uses horizontal bars, while a column chart uses vertical bars

   Answer: Area charts highlight change and magnitude across an ordered sequence, while column charts compare values across categories using vertical bars.

8. **Which statements accurately describe how data visualizations support storytelling with data? _(Select all that apply)_**
   - [ ] Visualizations are useful only for technical audiences who already understand the data.
   - [x] Visualizations help analysts decide which data points and comparisons to emphasize.
   - [x] Visualizations help stakeholders see patterns, trends, and comparisons more quickly than raw data alone.
   - [ ] Visualizations mainly make reports look more attractive without improving understanding.

   Answer: Effective visualizations require deliberate choices about what to highlight, which helps focus the story on the most important information. A well-chosen chart can make relationships in the data easier to interpret at a glance

9. **An analyst must choose a chart for a sales report. The report may either compare sales across regions or show how sales changed over the last 12 months. Which guideline best supports the chart choice?**
   - [ ] Use a time series chart to compare regions, and use a bar chart only when there is no time element.
   - [x] Use a bar chart to compare sales across regions, and use a time series chart to show changes over the last 12 months.
   - [ ] Use the same chart type in both cases so the report looks consistent.
   - [ ] Use a pie chart to compare regions, and use a scatter plot to show monthly sales trends.

   Answer: Bar charts are well suited for comparing categories, while time series charts are designed to show change over time.

10. **You created a 3-D Clustered Column PivotChart comparing BMW, Cadillac, and Hyundai models. You want BMW models expanded in the chart while the other manufacturers remain collapsed. What should you do?**
    - [ ] Filter the PivotChart to display only BMW models.
    - [x] Expand BMW models in the connected PivotTable, because the PivotChart reflects the PivotTable's expansion state.
    - [ ] Change the chart layout so BMW appears first in the series order.
    - [ ] Use the plus and minus buttons in the PivotChart to expand BMW and collapse Cadillac and Hyundai individually.

    Answer: To show BMW in detail while keeping other manufacturers collapsed, expand BMW in the connected PivotTable and let the PivotChart reflect that view.
