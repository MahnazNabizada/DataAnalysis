# Practice Quiz - Questions and Answers

## Modern Data Ecosystem and the Role of Data Analytics

1. Which emerging technology has made it possible for every enterprise to have access to limitless storage and high-performance computing?
   - [ ] Machine learning
   - [ ] Internet of Things
   - [x] Cloud computing
   - [ ] Big Data

   Answer: Cloud technologies have made it possible for every enterprise, regardless of its size, to have access to limitless storage and high-performance computing at nominal costs.

2. Which of the data roles is responsible for extracting, integrating, and organizing data into data repositories?
   - [x] Data Engineer
   - [ ] Business Intelligence Analyst
   - [ ] Data Scientist
   - [ ] Data Analyst

   Answer: Data Engineers are responsible for extracting, integrating, and organizing data into data repositories.

3. When you analyze historical data to predict future outcomes what type of Data Analytics are you performing?
   - [x] Predictive Analytics
   - [ ] Descriptive Analytics
   - [ ] Diagnostic Analytics
   - [ ] Prescriptive Analytics

   Answer: Predictive Analytics is the analysis of historical data to predict future outcomes.
